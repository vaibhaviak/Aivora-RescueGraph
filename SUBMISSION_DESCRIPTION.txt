Aivora RescueGraph is a financial resilience prototype that helps users rehearse compound financial shocks. Users enter a synthetic household cash-flow profile and apply events such as salary delays and unexpected expenses. A deterministic Python engine calculates month-by-month balances and detects the first negative month-end balance. A counterfactual intervention lab compares possible changes. Gemini can explain computed results when a valid API key and available model are configured. The Streamlit application is deployed on Google Cloud Run. Cloud Firestore persistence is available when configured with Google Cloud credentials and appropriate IAM. Firebase Authentication or Hosting must be added and verified separately before claiming those services are implemented. The prototype uses synthetic data only and does not connect to bank accounts, execute transactions, or provide regulated financial advice.
