Aivora RescueGraph is a financial resilience prototype for the BFSI - Intelligent Risk, Fraud & Financial Experiences theme. Users enter a synthetic household cash-flow profile and apply shocks such as salary delays and unexpected expenses. A deterministic Python engine calculates month-by-month balances, detects the first projected negative month-end balance, and compares hypothetical interventions. Optional Gemini explanations require valid API configuration; live authentication has not yet been verified. The Streamlit application is deployed on Google Cloud Run. The prototype uses synthetic data only; it does not connect to bank accounts, execute transactions, or provide regulated financial advice.
